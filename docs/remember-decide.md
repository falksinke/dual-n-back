# Remember & Decide

Open **Remember & Decide** from the Working Memory Trainer home. Each round alternates a highlighted grid location with a vertical-symmetry decision. After the final decision, select the remembered locations in order.

Before a round, choose a sequence length from two to eight, the number of differences in non-symmetrical patterns, and a three-, five-, or eight-second decision deadline. The default is three locations, More differences, and five seconds. The settings stay fixed until the round ends. The setup includes an unscored example.

During each decision, choose **Yes** or **No** before the deadline. A timeout counts as a decision error and moves to the next item. During recall, each selected cell is added to the numbered answer strip; the same cell can be selected more than once. Use **Undo** or **Clear** to revise the answer, then **Submit** once it contains the requested number of locations.

The result reports position-by-position recall, exact-sequence success, symmetry accuracy, and timeouts separately. It also shows both location sequences and each symmetry answer. **Try next length** appears after exact recall and at least 80% correct decisions, including a correct Yes and a correct No. At length three, all three decisions must be correct. Selecting it increases only the sequence length, up to eight. A round with only one pattern type receives its normal scores but cannot earn this suggestion. **New round** keeps the current settings, while **Settings** returns to setup.

During a round, choosing **Pause** or hiding the page discards the current attempt without a result. **Restart round** creates a fresh round with the same settings. Leaving the exercise clears its local state. This exercise stores no history and does not change N-back progress.
